[PORT ANALYSIS]
PORT 135 — Microsoft Windows RPC (Remote Procedure Call)
  - Used by Windows for inter-process communication (IPC).
  - Required by DCOM, WMI, and Task Scheduler services.
  - Security Note: Historically exploited by the Blaster worm (MS03-026).
    Must be blocked at the network perimeter; not required externally.

PORT 445 — SMB (Server Message Block / microsoft-ds)
  - Primary Windows protocol for file sharing, printer sharing, and
    Active Directory domain communication.
  - Security Note: Exploited by EternalBlue (MS17-010), which powered
    WannaCry and NotPetya ransomware in 2017. Must be patched (KB4012212+)
    and blocked from internet-facing interfaces.

PORT 2179 — VMRDP (Hyper-V Virtual Machine RDP)
  - Enables remote desktop access to Hyper-V virtual machines.
  - Confirmed by the presence of the vEthernet (Default Switch) adapter
    (172.22.144.1) found in ipconfig — Hyper-V is actively installed.
  - Security Note: Disable if remote VM access is not needed.
